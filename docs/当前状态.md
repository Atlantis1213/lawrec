# 当前状态：media-playback-dev（2026-09-30）

已发布的 v1.0.0-rc1 SD 镜像保持不变。工作区新增媒体开发版，双核程序必须配套更新；
这不是已经通过实板验收的正式版本。

## 已实现

- 音频基础模块：AI/AENC G.711A 8 kHz 单声道共享订阅、回调复制、有界队列、
  单路溢出隔离及清理失败隔离；大核新增音频专用 VB 池。双核 Docker 编译与
  生命周期 mock 通过，日志 `out/audio-build.log`、`out/audio-big-build.log`、
  `out/audio-tests.log`。RTSP 已接入共享音频队列和 G.711A 音轨，并移除独立 AI/AENC
  路径；新增 `audio_enabled=0/1` 和设置页开关，默认关闭、重启 UI 生效。
  本轮 Docker 编译与配置测试日志为 `out/rtsp-audio-build.log`、`out/rtsp-audio-tests.log`。
  MP4 已接入 G.711A 音轨，共用音频开关；实际麦克风、VLC 声音和音画同步均未实板验证。
- 录像音视频由同一 worker 写入，音频按下一视频帧边界排队，分段共用视频 IDR 的
  PTS 原点。首个视频写入后才创建音轨，绕开 SDK 预创建音轨误标 G.711U 的分支。
  修复 MP4 输入 PTS 重复毫秒换算，改为传入微秒。Docker 编译和分段/音轨 mock
  通过，见 `out/record-audio-build.log`、`out/record-audio-tests.log`。
  尚未验证真实 MP4 音轨、SDK 音视频同源时钟以及回放声音。
- 回放新增可选单声道 8 kHz G.711A/G.711U 音轨，通过物理 VB 缓冲送入 ADEC/AO，
  与视频共用播放时钟和暂停等待。仅接受一个 H.264 视频轨和最多一个受支持音轨，
  音频包不超过 320 字节。纯视频兼容、音频送流与绑定失败回收 mock 通过。
  Docker 编译通过但有生成文件时钟偏差警告，证据为 `out/playback-audio-build.log`、
  `out/playback-audio-tests.log`。AO 实际声音、音画偏差及暂停尾音未板测。
- RTSP 音视频统一 PTS 映射：会话共用墙钟基准，帧源不再以队列消费时间重打时间戳；
  迟到帧、系统时间跳变、重置和边界测试通过，见 `out/media-clock-tests.log`。
- 共享编码开发增量：新增 VENC0 单次初始化、多队列分发、晚加入等待自包含 IDR、
  独立退出及失败隔离。录像和 RTSP 都已接入，控制层允许并发，回放仍独占媒体。
  RTSP 消费线程退出后才销毁 live555，最后一个订阅者退出才释放 VENC。
  Docker 构建通过（构建生成文件有亚秒级时钟偏差警告，改动源码已重新编译）；
  本轮证据在 `out/shared-build.log`、`out/shared-tests.log`，尚未部署或实板验证。
- 录像 SDK 回调不再执行 MP4/文件同步，改为录像 worker 消费有界队列（64 帧/8 MiB）；
  队列和共享 VENC 模拟测试通过，日志 `out/encoder-tests.log`、`out/encoder-build.log`。
- 设置开发增量：真实 IPv4 状态、RTSP 端口原子保存（UI 重启生效）、
  WPA2-PSK 热点输入与二次确认保存（板子下次启动生效），保存操作不触发在线切网。
- 媒体参数升级为版本化 `/etc/lawrec-media.conf`：端口和视频码率整体原子保存，
  旧端口文件向前兼容读取；RTSP/录像共用启动快照，码率传入共享 VENC 初始化。
  UI 支持调节码率及选择默认值；配置测试和 Docker 编译通过，实际码率待板测。
- 网络扫描/关联状态查询已通过 supplicant 控制 socket 接入，后台执行，UI 可浏览热点、
  选取 SSID；Docker 模拟测试通过，实板扫描待验收。
- 在线切换与失败回滚已接入控制 socket 和 DHCP 调度，事务模拟测试通过；
  实板换网/回滚未执行，长期租约管理、静态 IP/DNS 和参数扩展尚未完成。
- 增加显式确认的 DHCP 更新入口、超时/取消/进程回收；代码与 Docker 测试通过，
  没有在当前 SSH 连接上执行更新，实板验收仍待进行。
- 保留单 Linux 业务进程，停用 standalone service/demo 默认构建及安装。
- 建立 Git 迁移基线，Docker 构建入口和可追溯候选包。
- 双核共用命令表，预览回包携带版本、序号和结果；超时/迟到回包处理。
- UI 后台 IPC 状态改为由 UI 主循环刷新；本地命令使用有界串行队列。
- UI 独占锁和 SIGTERM/SIGINT 媒体收尾，停止等待以 worker 完成为条件。
- 小核媒体租约允许 RTSP/录像共享，回放独占；复用大核 VB，保持 SDK 客户端连接。
- RTSP 启动返回值检查、实际回调就绪、8 秒无帧失败、队列上限和 IDR 恢复。
- 修复 SessionAttr 中 std::string 被 memset 清零、Base64 new[]/free 不匹配及 SDP 泄漏。
- 录像只支持首版 H.264；首个带 SPS/PPS 的 IDR 写入后确认录制，增加无帧/容量检查。
- 新增纯视频按 IDR 分段开发版：保留 SPS/PPS、每段独立零基 PTS，关闭成功才发布；
  达到时长请求 IDR，超时失败停止。设置支持关闭或选择 60/180/300/600 秒，UI 重启生效。
  实际录像回调的 SDK mock 测试通过，真实 MP4 段首解码/段间连续性待板测。

- 文件页浏览、大小/容量、删除确认、SCP 导出提示；录像进度和错误码显示。
- 录像与RTSP启动期间的worker生命周期提前占位，避免stop_wait提前完成。

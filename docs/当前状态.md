# 当前状态：v1.0.0-rc1 软件候选版

## 已实现

- 保留单 Linux 业务进程，停用 standalone service/demo 默认构建及安装。
- 建立 Git 迁移基线，Docker 构建入口和可追溯候选包。
- 双核共用命令表，预览回包携带版本、序号和结果；超时/迟到回包处理。
- UI 后台 IPC 状态改为由 UI 主循环刷新；本地命令使用有界串行队列。
- UI 独占锁和 SIGTERM/SIGINT 媒体收尾，停止等待以 worker 完成为条件。
- 小核媒体独占租约，复用大核 VB；保持 SDK 客户端连接，避免模块互相关闭。
- RTSP 启动返回值检查、实际回调就绪、8 秒无帧失败、队列上限和 IDR 恢复。
- 修复 SessionAttr 中 std::string 被 memset 清零、Base64 new[]/free 不匹配及 SDP 泄漏。
- 录像只支持首版 H.264；首个带 SPS/PPS 的 IDR 写入后确认录制，增加无帧/容量检查。
- 可配置持久化目录、128 MiB 保留空间、唯一临时文件、成功封装才发布 MP4。
- 文件页浏览、大小/容量、删除确认、SCP 导出提示；录像进度和错误码显示。

## 已验证与待验证

- Docker 软件测试：存储路径、文件发布、唯一命名和删除过滤；Annex-B 起始码/短输入。
- Docker 构建：以 out 下本轮构建日志及候选包 BUILD.txt 为准。
- 板端按键、VLC 拉流、生成 MP4 解码、存储持久性、50 次启停和长测均待验收。
- 当前没有可确认的板端 IP、正在运行的版本、串口日志及存储挂载证据。

## 尚未完成

- SDK 同步调用硬阻塞无法由应用取消，媒体清理失败后需重启。
- 双 VENC 并发尚未板测，所以第一版明确互斥，不宣称并发能力。
- 分段、音频、本地回放、完整网络设置、AI 业务和断电恢复不在本候选包内。
- 不生成正式 v1.0.0 标签；板端验收通过后再发布正式大版本。

```sh
bash tools/build.sh big
bash tools/build.sh little
```

两个命令均已成功。大核产物为 `out/big/lawrec.elf`；小核产物仍安装到
SDK 的 `output/k230_canmv_lckfb_defconfig/little/buildroot-ext/target/app/lawrec`。

构建入口挂载 SDK 实际路径及 `/home/atlantis/k230_sdk` 兼容路径，后者用于
当前 Buildroot 缓存中的历史绝对路径。更换机器需重建相关缓存或调整兼容挂载。
新入口使用调用者 UID/GID；本次只修复项目旧产物、lawrec 构建缓存、target
中 lawrec 安装目录和 S99lawrec 的历史 root 所有权。

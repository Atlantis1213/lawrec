# lawrec 录像功能实现说明

## 1. 本次实现边界

- 录像沿用当前正式工程骨架接入：
  - `UI -> msg_proc -> control -> record module`
- 不新增临时脚本。
- 不新增独立 demo 可执行文件。
- 只复用 SDK 官方 `kd_mapi_*` 与 `kd_mp4_*` API。

## 2. 当前实现逻辑

### 2.1 小核

- `ui/src/scr_preview.c`
  - 录像按钮负责开始/停止录像。
  - 退出预览时，如果录像仍在进行，会先停录像，再退出预览。

- `ui/src/msg_proc.cpp`
  - 和 RTSP 一样，录像命令优先在小核本地短路处理。
  - 本地状态轮询线程把录像状态回推给 UI。

- `control/src/lawrec_control.cpp`
  - 统一管理 `preview_active / rtsp_enabled / record_enabled`。
  - 当前规则：
    - preview 未 ready，不允许启动录像；
    - preview 退出时，录像必须同步停止。

- `record/src/lawrec_record_entry.cpp`
  - 录像模块运行在正式工程内部。
  - 使用 `kd_mapi_venc_*` 建编码通道；
  - 使用 `kd_mp4_*` 创建 MP4 文件并写入码流。

### 2.2 大核

- 本次录像首版没有新增大核 IPC 命令。
- 大核继续负责底层预览/采集链存活。
- 小核录像模块通过 MAPI 绑定现有 VI 输出通道取编码数据。

## 3. 当前录像状态机

- `IDLE`
- `STARTING`
- `RECORDING`
- `STOPPING`
- `FAILED`

录像状态 owner 仍然是小核 `control + record module`，不放在 UI 控件本地硬编码。

## 4. 当前默认参数

- 编码格式：`H.264`
- 分辨率：`1280x720`
- 输出目录：`/tmp/lawrec_records`
- 文件名：`lawrec_YYYYMMDD_HHMMSS.mp4`

## 5. 当前已知说明

- 首版优先打通“进入拍摄 -> 点录像 -> 生成 MP4 -> 停止录像”的主链路。
- 当前没有接入音频轨。
- 当前没有新增新的大小核脚本控制链。

## 6. 后续建议

- 补录像列表页与回放页联动。
- 补剩余容量、录制时长、文件大小显示。
- 补音频轨封装。
- 若后续要长期支持 RTSP 与录像并发，再继续收敛统一编码扇出模型。

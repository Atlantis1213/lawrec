# 触控 ST7701 PHY 两 lane 测试

本页保留历史测试步骤。当前已按用户要求恢复 27 MHz 和 K_DSI_4LAN，
最新固件及操作见 [LCKFB 面板序列测试](触控LCKFB_PANEL分段测试_2026-10-01.md)。

## 本轮只改 lane

按用户请求，在 SDK `src/big/mpp/kernel/connector/src/st7701.c` 中改为：

```c
mipi_phy_attr.phy_lan_num = K_DSI_2LAN;
```

原值为 `K_DSI_4LAN`。本地驱动处理的 480x800、480x854 两个 ST7701 屏型均
标为两 lane，本轮修改影响这两个屏型；未改其它 connector 驱动。调用后增加
唯一内核标记用于识别新固件：

```text
[touch-test] PHY_2LAN: ST7701 requested two lanes
```

保持 24.75 MHz / 297 Mbps 应用参数、DSI 内部图案、单独 timestamp 调用和
跳过最终 VO enable 不变。触控驱动、滤波、坐标、面板命令不改。
用户未提供上一轮 24.75 MHz 的具体结果，本页不推断其失败或正常。

## 更新与运行

此改动位于大核内核，单独 SCP 应用不生效。本页采用前几轮的整卡烧录方式，
不会自动写板端分区。若只更新 RTT 分区，应先核实当前分区和固件更新方式，
不能把 bin 随意写入 SD。

1. 先导出要保留的录像和配置。Windows 打开以下目录，用 balenaEtcher 烧录
   `sysimage-touch-phy-2lane.img`；整卡烧录覆盖 SD 数据。

   ```text
   \\wsl$\Ubuntu\home\atlantis\lawrec\out\touch-phy-2lane\20261001T091644Z\artifacts
   ```

2. 完整断电上电，不启动 UI 或其它大核应用。整卡重刷会清除 sharefs 中此前
   上传的文件，重新上传同一个测试 ELF，IP 按板端当前地址调整：

   ```powershell
   scp "\\wsl$\Ubuntu\home\atlantis\lawrec\out\touch-phy-2lane\20261001T091644Z\artifacts\lawrec-touch-lckfb-24750.elf" root@192.168.123.74:/sharefs/lawrec-touch-lckfb-24750.elf
   ```

3. 等 SCP 成功结束，小核校验 SHA256 与上面的应用值一致，再运行 evtest：

   ```sh
   sha256sum /sharefs/lawrec-touch-lckfb-24750.elf
   chmod +x /sharefs/lawrec-touch-lckfb-24750.elf
   evtest /dev/input/event0
   ```

4. 大核串口执行，无需模型参数：

   ```sh
   /sharefs/lawrec-touch-lckfb-24750.elf
   ```

   必须看到新 `PHY_2LAN` 内核标记及原 `TIMESTAMP_ONLY: no VO enable`，
   connector 返回 0；应用打印参数应仍为 24750/297000。
   应用旧文字 `TIMESTAMP_ONLY kernel unchanged` 只是在上一轮归档中保留的
   提示，本轮内核 lane 确实改了，不能用这段旧文字判断固件版本。

5. 观察图案及触控 30～60 秒，先松手 10 秒，再点击中央/四角，再观察释放。
   记录图案是否正常、无人触碰时是否上报、是否迟钝、DOWN/UP 是否完整。
   测试 ELF 退出不会恢复硬件，下一次对照需完整断电上电。

## 判断与回退

| 结果 | 下一步 |
| --- | --- |
| 图案正常，本次窗口未见鬼触 | 支持 lane 配置参与影响；还需正常 VO/UI 显示验证，不能宣布永久修复 |
| 图案正常，仍异常 | 保留时序和 lane 变量，下一轮对比官方完整面板初始化命令及显示侧实际状态 |
| 图案异常或不显示 | 先恢复四 lane 固件对照，单独换 ELF 无法恢复 PHY lane |
| 缺少新标记或初始化失败 | 先检查烧录版本、程序和初始化返回，不作触控归因 |

四 lane 对照镜像：`out/touch-timestamp/20261001T075532Z/artifacts/`，配合同一个
24.75 MHz 应用。两 lane 镜像仍跳过最终 VO enable，只用于定位，不运行正常
UI、摄像头、RTSP、录像或回放业务。

## 当前实现

复用 SDK BusyBox 1.33 udhcpc，不自建 DHCP 协议栈。首次获取使用 `-n -t 4 -T 3`，
最新地址冲突增量增加 `-a2000`，外层等待从 20 秒增至 30 秒；没有 `-q/-f/-b`。
新增租约在 hook 配置前严格 ARP 检查，同地址/掩码续租不重复完整检查；
详见 [IPv4 地址冲突检测](IPv4地址冲突检测_2026-10-01.md)。
首次 ACK 后 BusyBox 清除初次失败退出策略，
自行后台化，后续按其租约状态机续租。客户端独立于 UI 生命周期，不因退出 UI
而失去续租。静态模式不会启动 DHCP。

`lawrec_dhcp.cpp` 管理 `/var/run/lawrec-dhcp-XXXXXX/`，包含 pid、hook、lease 和
events.log；current 文件指向唯一 job，跨进程 flock 避免重叠启动/停止。
操作前通过 pidfd 固定进程并核对可执行参数、wlan0、唯一 PID/hook 路径。
兼容后台化时 PID 文件暂未重写的窗口，不按进程名称杀全局 udhcpc。
停止发送 SIGTERM 并最多等待 3 秒，失败保留元数据，不强杀正在改网络的 hook。

hook 使用同一 UI 的 `--dhcp-hook EVENT JOB`，在 DRM、媒体、IPC 初始化前返回。
bound/renew 校验地址、掩码、网关、DNS 和 lease 后，只配置 wlan0 的 IPv4/default
路由和带 wlan0 标记的 DNS，保留其它接口配置。只有全部成功才记录 bound。
同一地址/掩码的 renew 不 flush 地址；deconfig 清除本接口地址/default 路由/DNS，
nak/leasefail 标记失败。状态快照提供 PID、bound、error 和原租约秒数；上述历史
实现没有剩余倒计时，最新页面已按顶部增量显示有效/异常和剩余时间，不直接显示 PID。

手动 Renew IP 替换自有客户端；换热点在 SELECT 前等待旧客户端退出，失败则不
切换，回滚重建旧热点租约。S45wifi 用 `--dhcp-stop` 在重建连接或停网前回收客户端。
首次获取成功还必须同时确认客户端存活与 hook 成功，不能仅凭旧 IP 宣称成功。

## 边界与最小板测

- 依赖 Linux pidfd_open/pidfd_send_signal；不支持时启动前失败，不退回不安全杀 PID。
- 仅支持 wlan0 普通 IPv4、/1 至 /30 掩码、最多两个 DNS；classless staticroutes
  返回 ENOTSUP。DNS 可缺省，但此时不保证域名可解析。
- 客户端崩溃会上报未 bound/ENETDOWN，没有自动崩溃拉起 supervisor；显式 Renew
  可重建。hook 失败可能留下部分网络配置，不宣称自动回滚或断电恢复。
- 模拟不发送 DHCP 报文，也不执行真实 ip/DNS hook，不能证明 T1/T2 或租约到期恢复。

触控诊断结束并恢复业务显示链后，用串口保底及可控路由器短租约验证：
首次联网、T1/T2、租约到期重获；退出/重启 UI 后客户端持续；换热点/失败回滚无
残留客户端；eth0 路由/DNS 不受影响。查看 `/tmp/lawrec-dhcp.log`、当前 job 的
events.log 和 `/tmp/wifi-autoconnect.log`。不要在唯一 SSH 通道无串口保障时切网。

# 录像目录设置

## 用户入口与边界

Settings -> Storage：编辑目录，Check 检查，Default 仅填写默认值，Save 二次确认。
目录必须先在已确认的持久化分区创建，程序不 mkdir/格式化、不搬移或删除旧录像。
保存只更新 `/etc/lawrec-record-dir`；当前进程继续使用原目录，重启 UI 才加载新值。
`LAWREC_RECORD_DIR` 调试环境覆盖优先，UI 保存不会撤销环境覆盖。

保留单行绝对路径的旧文件格式（可无换行，或结尾 LF/CRLF），没有新增重复配置。
读取/校验/快照/原子保存集中在 settings 模块，存储模块负责实际文件系统操作。
缺失配置采用 `/sharefs/lawrec_records`；非法文件返回错误，显示默认值不代表
已应用默认目录。录像、文件列表、删除、回放打开均拒绝错误配置，不静默换位置。

## 限制与防护

- 路径最多 80 字节，规范绝对 ASCII 路径，允许字母、数字、点、下划线、横线、
  斜线；拒绝根目录、重复/末尾斜线、`.`/`..` 分量、空白、控制字符和多行。
  SDK muxer `file_name[128]` 是硬限制；生成路径再次核对小于 128 字节，避免截断。
- 配置只读普通文件，大小有界，O_NOFOLLOW/O_NONBLOCK 拒绝链接/FIFO；保存用
  0600 临时文件、fsync、原子替换和目录同步。只防普通更新中断，不保证掉电恢复。
- 存储路径逐组件 openat/O_DIRECTORY/O_NOFOLLOW，拒绝中间或末尾符号链接。
  空间查询使用目录 fd；拒绝 tmpfs/ramfs、只读与低于 128 MiB 可用空间。
- Check/Save 实际独占创建小型 `.lawrec-probe-*`，写入/fsync、删除并同步目录。
  检查失败不保存；空间低时仍可浏览、导出、删除已有完整录像。
- `.part` 用目录 fd 和随机后缀独占创建，不覆盖旧录像；完成后仍使用
  RENAME_NOREPLACE 发布 MP4。随机源暂未就绪会返回 EAGAIN，可重试，不无限等待。

文件系统写入/fsync 是同步调用，坏盘时没有硬超时保证；Check/Save 页面操作可能
等待存储返回。检测通过不证明实际 SD 持久性或 MP4 可播放，也不保护运行中由管理员
卸载/替换目录的行为。现阶段不要在录像/回放中卸载存储。

## 最小板测

完成触控诊断并恢复业务显示链后，用已确认的 SD 目录验证：Check 后无 probe 残留；
Save 时原目录继续录制/浏览；正常停止并重启 UI 后新目录生效，录像可播放且重启
仍在；旧目录文件未移动/删除，可用 SCP 导出。再验证缺失目录、只读挂载、低空间
和非法配置的错误提示。不要自动格式化或在现有录像盘上破坏数据做测试。
视频档位、损坏 MP4 健壮性及全链路媒体/网络/异常实板验收仍待完成。

# 音频接入实施记录

## 已落地

- `lawrec_audio` 通过 MAPI AI/AENC API 管理大核音频采集与 G.711A 编码，不启动 demo。
- 输出为 8 kHz 单声道，40 ms 一帧；内部 codec 使用 SDK 标注为 mic input 的右声道。
- owner1=RTSP、owner2=录像，共用一个 AI/AENC，首订阅启动、最后退订清理。
- 回调复制 SDK 内存后分发不可变帧，保留 SDK 微秒时间戳；不在回调写文件或发网络。
- 初始化失败逐项回收，零值 AI handle 也正常清理；清理失败后拒绝重新启动。
- 大核预留 50 个 2560 字节采集块、25 个 5120 字节播放块，避免占用摄像头大块。

## 下一步接线

1. 已添加持久化音频开关，默认关闭、重启 UI 生效，兼容无此字段的旧配置。
2. RTSP 已移除独立 AI/AENC，消费共享音频队列，建立 G.711A SDP 音轨；
   8 秒无音频或队列异常触发失败，先退出消费者再销毁音轨。
3. 录像已在同一 worker 写入 MP4 音视频轨，以首个视频 IDR 为每段共同 PTS 原点；
   丢弃原点之前音频，分段按视频边界分配音频，不使用两个互不相关的零基时间戳。
   音轨在首个视频写入后创建，绕开 SDK 将预创建音轨硬编码为 G.711U 的问题。
   SDK 写入接口使用微秒，现已修复先转毫秒后重复换算的错误；音轨和视频均传微秒。
   无音频段不发布；音频队列异常、8 秒无进展都会停止并报错。
4. 本地回放已添加 ADEC/AO，支持 G.711A/U 单声道 8 kHz（每包最多 320 字节），
   音视频同一个 worker 按 PTS 调度、同步暂停，不关闭全局显示链。
   复用物理 VB 缓冲送流，失败时先清理解码器再释放输入块。
   ADEC 没有 EOS 查询接口，结束时只等待末包标称时长，不等同硬件 drain 确认；
   暂停会停止继续送包，但已提交硬件的短尾音仍需实板评估。
5. 验证实际麦克风通路、音视频 SDK 时钟一致性、VLC 音频、MP4 兼容性和独立停用。

# 竖屏映射与预览黑屏诊断

## 已有证据

- 实板多次 enter/exit 返回0、bound=1/0，说明预览 IPC 及绑定调用已通；不证明画面正常。
- 启动日志曾报告空闲黑帧分配失败；本轮隔离其缓冲池，不把它直接认作黑屏根因。
- 预览页背景及 LVGL 屏幕配置支持透明；仍需查实际帧缓冲 alpha 和硬件显示状态。
- 用户确认板端离线，本轮没有上传、重启或刷写。

## 本轮修改

1. 仅 LCKFB 使用现有 reflect-X：归一化到480x800后，x=479-x、Y不变。
2. VO 属性设置和层启用改用逐项检查的 MPI 调用，SDK 示例 helper 原先忽略返回值。
3. 解绑失败返回实际错误并保留 bound，允许后续重试；空回调不能误报绑定成功。
4. 空闲黑帧改用独立单块 VB 池，分配失败不误判摄像头链路失败；停用层后释放。
5. backend ready 在启动空闲处理完成后发布，避免并发 enter 被启动解绑覆盖。
6. 主循环观察到预览进入时，取一次通道0帧（等待上限500ms），打印尺寸/格式/
   stride/PTS/物理地址并释放；不是持续抓帧，也不改变 IPC 成功语义。
7. UI 中央像素透明度变化时记录日志，用于判断预览窗口是否被不透明像素覆盖。
8. app_run 改为线程安全访问；SIGINT 只设置退出标记，退出路径拒绝新 enter；
   无 /dev/tty 时使用非阻塞 stdin，避免退出线程卡在 getchar。其他 SDK 退出等待仍需实测。

显示时钟27MHz、PHY324Mbps、分频21、n3/m52/voc0x1f/hs0xb5、K_DSI_4LAN、
ST7701 面板序列及 Linux 触摸驱动保持不变。本轮无需重编内核。

## 更新包

`out/touch-preview/20261001T164338Z/` 包含 lawrec.elf、ui、liblv_drivers.so、
liblvgl.so、配套 S45wifi 和 SHA256SUMS。这是应用更新包，不是 SD 镜像。

特别注意：映射在 **liblv_drivers.so**，只复制 ui 不会更新映射。
板端联网后先停止 UI、大核业务程序并用 list_process 确认，不能在旧大核仍存活时
重复启动。完整断电后再启动也可以，操作由用户执行。

后续上传示例（主机执行；先在板端按需 remount 根文件系统为可写）：

```bash
cd /home/atlantis/lawrec/out/touch-preview/20261001T164338Z
sha256sum -c SHA256SUMS
scp lawrec.elf root@192.168.123.74:/sharefs/lawrec.elf
scp ui root@192.168.123.74:/app/lawrec/ui/ui
scp liblv_drivers.so liblvgl.so root@192.168.123.74:/usr/lib/
scp S45wifi root@192.168.123.74:/etc/init.d/S45wifi
```

复制动态库前必须停止 UI；不要在本轮运行 S45wifi 或切换网络策略。
板端执行 chmod +x /sharefs/lawrec.elf /app/lawrec/ui/ui /etc/init.d/S45wifi、sync，
并与本地 SHA256SUMS 逐项核对。若板端 IP 改变，替换上面的地址。

## 最小验收

1. 大核 msh 手动运行 `/sharefs/lawrec.elf /bin/retinaface.kmodel /bin/mbface.kmodel`，
   等待 backend ready。此包不覆盖 ROMFS 的 /bin/fastboot_app.elf，别启动旧副本。
2. Linux 手动运行 `LAWREC_TOUCH_ENABLE=1 /app/lawrec/ui/ui`，确认日志中有
   `touch map=reflect-x`；点左右两侧按钮确认方向。
3. 只进入预览一次，收集大核 `[lawrec-preview]` 日志和 Linux `/tmp/lawrec.log`。

判断：`frame probe failed` 优先查 VICAP/传感器/VB；取得800x480帧说明该时刻取帧
成功，但不保证后续帧或图像内容正常。若同时 UI 中央 alpha=0/15、VO 属性和启用
均成功而仍黑屏，下一步查帧内容、VO地址/旋转及大小核共享显示寄存器。
alpha=15/15 表示中央像素不透明，应先查 UI 遮挡。单个中央像素不能代表整个 UI。

## 离线验证

Docker 唯一入口：`bash tools/build.sh big`、`bash tools/build.sh little`，两者通过。
`bash tools/test.sh touch` 覆盖左右端点/中心及按下释放；
`bash tools/test.sh preview` 覆盖空回调、解绑失败、黑帧私有池及取帧释放，两者通过。
这些测试不是实板显示验证。日志在 `out/touch-preview-*-build.log`、
`out/touch-preview-mapping-tests.log`、`out/touch-preview-controller-tests.log`。

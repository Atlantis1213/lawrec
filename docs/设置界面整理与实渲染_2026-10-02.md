## 本轮目标

推进 M4 的设置交互：把小屏上的密集按钮、长状态文本和参数混排，整理成
“分类入口 → 单项编辑 → 明确确认 → 结果反馈”。保持已有媒体、网络、存储和
校时后台语义，不同时改动已通过触控实验的显示时序。

## 页面与生效方式

| 页面 | 操作 | 生效方式 |
| --- | --- | --- |
| 系统设置 | 视频与录像 / 网络 / 存储 / 时间四个大入口 | 导航，不修改业务 |
| 视频与录像 | 15/30 FPS、码率、RTSP 端口、音频、分段 | 确认保存后重启 UI；当前流参数不变 |
| 网络连接 | 扫描、选择热点、输入/隐藏密码 | 扫描不切网；选热点不自动连接 |
| 网络连接 | 保存 WiFi / 立即连接 / 重新获取 IP | 保存供下次启动；在线操作另行确认，可能断开 SSH |
| IPv4 地址设置 | DHCP / 静态 IP、前缀、网关、双 DNS | 保存供下次开机；立即应用只改当前网络，不自动保存 |
| 录像存储 | 编辑、检查、保存目录 | 检查现有目录；保存后重启 UI，不创建目录或搬移文件 |
| 系统时间 | 查看、填入、校准 UTC | 仅更新系统时钟；媒体活跃时由控制层拒绝，不更新 RTC/NTP |

DHCP 下不显示静态输入框。视频、存储、WiFi、IPv4 页离开时会确认放弃未保存
修改；取消继续编辑。WiFi 到 IPv4 的子页导航保留草稿；IPv4 返回后再进入会
重新读取已保存配置。草稿不自动保存，放弃不会回滚当前网络。视频页恢复默认
也只是编辑草稿，仍需独立保存。

## 交互与结构

- 480×800 竖屏保持既有深青色风格；统一标题区、可滚动卡片区和固定底部操作区。
- 操作按钮及输入框高 56 像素，分类入口高 104 像素；长内容滚动，不压缩全部按钮到一屏。
- 内容超出时显示高对比度滚动条，提示下方还有选项；键盘展开后也保留滚动指示。
- 点输入框才显示键盘，编辑区同步缩短并滚动到当前字段；完成/收起恢复底部操作。
- 端口/IP 使用数字键盘，UTC 使用数字、短横线、冒号和空格专用键盘。
- 高风险操作使用遮罩确认框，默认 GPIO 焦点在取消；关闭后恢复原页面焦点组。
- 确认框展示时冻结参数，确认后使用该快照；取消不调用保存、连接或校时 API。
- WiFi 密码默认遮挡，确认用的第二份明文在提交、取消或离开弹窗后清除。
- SSID 超过 32 字节明确拒绝，不能悄悄截断为另一个热点名称。

通用布局与键盘/弹窗集中在 `little/src/ui/src/settings_ui.{h,c}`。
`scr_settings.c` 管理分类入口和媒体页，网络、IPv4、存储、时间各有独立页面。
没有新增服务进程，也没有改变后台事务、共享编码器或媒体资源归属。

## 本轮修复与验证

真实截图发现 LVGL 键盘构造器默认设为底部居中；直接设置 y=520 是偏移量，
会把键盘推到屏幕外。现先恢复左上锚点，键盘实际区域为 (0,520) 到 (479,799)。
同时修正单行输入框自动改高度的问题，补齐中文子集字库，并为键盘显式使用含
图标的 Montserrat 字体，避免删除/完成按键显示方框。

Docker 渲染与精简交互检查通过，覆盖六个初始页面及十个交互状态；检查键盘
实际坐标、输入框不被遮挡、真实完成键事件、弹窗焦点恢复、取消不调用后台、
确认快照不变，以及保存和在线操作分离。小核目标构建通过，检查日志未见警告。
日志：`out/ui-preview-after.log`、`out/ui-fonts.log`、`out/settings-ui-build.log`。
这些检查针对 UI 集成，不重复跑整套媒体/网络模拟测试，不替代实际后台验收。

# 文件分页与回放界面

本轮继续 M3/M4 的文件管理和回放交互，只修改小核业务与离线渲染工具。
不改变已通过的 27 MHz / 324 Mbps / 4 lane / LCKFB 面板序列与触控映射；
不部署、不切网、不重建整卡镜像。

## 用户侧变化

| 页面 | 当前实现 |
| --- | --- |
| 录像文件 | 首屏四条文件及上一页/下一页；目录、空间与刷新集中为紧凑状态区 |
| 文件详情 | 点击查看完整名称、大小及支持格式；下方说明 SCP 导出，不虚构 HTTP 下载服务 |
| 删除确认 | 显示目标文件和大小，默认取消；确认前冻结目标，确认后重新核对身份 |
| 录像回放 | 中文状态、真实检测到的音轨、时间及只读进度条、暂停/继续、返回停止 |
| 停止/异常 | 等待 worker 退出才返回；清理失败明确提示媒体资源保留，禁止再播放/删除 |

设置继续采用四个分类入口、滚动卡片、固定底部操作区与独立确认框。
大核视频为 480×270、y=200..469；回放 UI 顶栏结束于 y=187、底栏始于 y=488，
中间保持透明，不用全屏不透明设置页覆盖视频。

## 实现与防护

- `lawrec_storage_page()` 按文件名倒序，使用文件名游标而非偏移量；向前翻页
  选取离游标最近的较新文件。扫描内存只保留单页（API 上限 32 条），没有原来
  列表的 1000 文件截断。UI 每页四条，不需要保存整目录或无限翻页历史。
  旧文本 API 保留为同一分页扫描器的有界适配，不再维护另一套排序逻辑，未完整
  返回时明确报 `-ENOSPC`；当前 UI 不使用它。
- 仅显示 `lawrec_*.mp4` 的非空普通文件，拒绝超长/非白名单名称、换行、反斜杠、
  符号链接与 `.part`。排序依据文件名，不声称文件名时间等同可靠拍摄时间。
- 元数据来自已打开目录的 `fstatat(..., AT_SYMLINK_NOFOLLOW)`，没有再由 UI
  拼接路径后直接 `stat()`。删除重新比较设备、inode、大小和纳秒 mtime，变化
  返回 `-ESTALE`；重新刷新选择后才可再次确认，取消不会删除。
- 上述校验与 `unlinkat()` **不是针对外部并发重命名的原子事务**。目录建议只由
  本项目管理；不要宣称可阻止任意外部进程在最终检查和删除间换名。
- 单页扫描仍同步遍历目录；内存有界不等于磁盘 I/O 有硬超时。外部大量增删
  文件不提供跨页快照一致性，可以刷新回最新页。
- `lawrec_playback_status` 新增文件名、检测到的音轨和资源保留标志。`active`
  表示 worker 存活；资源隔离失败时 `lawrec_playback_active()` 继续为真，不因
  worker 退出就放行新回放。设备维护仅恢复显示，不回收这些 codec/VB 资源。
- 音轨提示是 MP4 元数据检测结果，不是扬声器已发声的证据；进度来自提交帧
  PTS 和容器时长，不是实测显示/音频位置。本轮不增加跳转、倍速或新解码格式。

## 实渲染与验证

图库：[实际 LVGL 页面](../out/ui-preview/current/index.html)。使用生产页面源码、
LVGL 配置与中文字库；后台数据由 fixture 提供，不是真实文件、网络或视频。
回放截图中黑色区域是留给大核视频的透明窗口，不代表摄像头/解码器黑屏。

![文件首屏](../out/ui-preview/current/files.png)
![回放布局](../out/ui-preview/current/playback-playing.png)

均通过 Docker 执行的精简验证：

```bash
bash tools/test.sh files
bash tools/test.sh playback
bash tools/update-ui-fonts.sh
bash tools/render-ui.sh out/ui-preview/current
bash tools/build.sh little
```

文件测试覆盖 1005 个文件完整遍历、双向分页、空目录、非法文件过滤、修改/
换名后拒绝删除及匹配删除。回放测试使用生产 worker 和 SDK mock，补查名称、
音轨、时长和资源保留状态。LVGL 检查四条文件和翻页按钮首屏可见、取消不删、
确认目标冻结、空/错误/保留状态禁用、暂停继续、停止等待和视频窗口不遮挡。
沿用设置键盘、弹窗焦点和保存/在线操作分离检查，不重复跑整套网络/媒体测试。

证据日志：`out/files-ui-{storage-tests,playback-tests,fonts,render,little-build}.log`。
本轮未修改大核，不重复编译大核；最新小核哈希记录在《当前状态》。

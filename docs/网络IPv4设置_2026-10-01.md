# 网络 IPv4 设置

## 用户入口

WiFi 页面新增 IPv4 按钮。支持 wlan0 的 DHCP 或静态 IPv4，静态模式填写地址、
前缀 /1~/30、可选同网段网关、必填 DNS1、可选 DNS2。不接受网络/广播地址、
回环、多播、未知字段、重复字段、溢出或字符串注入。

Save 需要二次确认，仅保存下次启动配置，不改变当前 SSH/RTSP 地址。
在线 WiFi Connect/失败回滚继续使用本次启动已生效模式。静态模式下 Renew IP
返回 ENOTSUP，不能悄悄覆盖为 DHCP。WiFi 凭据和 IPv4 策略分别保存。
现已提供独立 Apply Now 在线应用及失败恢复，见
[IPv4 在线应用](IPv4在线应用_2026-10-01.md)。Save 仍不改变当前连接。
软件增量不能代表完整网络模块已实板交付。

## 实现路径

1. `lawrec_settings.cpp` 使用同一原子保存器写 `/etc/lawrec-ipv4.conf`，权限 0600。
   读取限制为普通文件、大小有界、不跟随符号链接，整份校验，非法配置不应用。
2. `little/S45wifi start` 先运行 `ui --ipv4-stage`，冻结到
   `/var/run/lawrec-ipv4-boot.conf`，再启动延迟关联 worker，防止 UI 保存新草稿
   被误当作当前启动配置。关联成功后调用 `ui --ipv4-boot`。
3. 两个 headless 入口都在 UI 独占锁、DRM/LVGL、IPC 和媒体初始化前返回，
   不产生第二个显示/采集实例。正常 UI 启动方式不变。
4. DHCP 使用有界首次获取和持续运行的自有 udhcpc 客户端，具体见
   [DHCP 持续续租](DHCP持续续租_2026-10-01.md)；静态模式用 argv 调用 `/sbin/ip`，只清理和配置
   wlan0 的路由/全局 IPv4 地址，可选默认路由 metric=600，不删除 eth0 路由。
5. 本 SDK `/etc/resolv.conf` 指向 `/tmp/resolv.conf`，原子替换目标而保留符号链接。
   仅替换带 `# wlan0` 的旧 DNS/search 条目，保留其它接口及未标记条目。
   不支持的 resolver 布局返回错误，不随意重写其它路径。
6. 成功才写 `/var/run/lawrec-ipv4.conf` 运行态并清除 incomplete 标记；中途失败
   不伪装为 DHCP 成功。此时拒绝在线换网/更新，先通过串口检查并修复配置。

启动脚本只停止 PID、可执行文件和 wlan0 参数匹配的自有 supplicant。
发现外部 supplicant 则拒绝替换；不再 `killall udhcpc/wpa_supplicant`。
启动/更新与在线请求检查 worker/文件锁，不能打断尚未完成的 IP 应用。
若 helper 中途异常终止，部分地址可能已配置；incomplete 标记并非自动回滚证明。

## 最小实板验收

触控诊断结束、恢复完整业务显示链后，先保存 DHCP 配置并重启，检查新脚本能
关联/分配地址且 UI 正常；再使用路由器预留的空闲地址配置静态 IP，保存时
SSH 不应断开，重启后核对 `ip -4 addr show dev wlan0`、`ip -4 route` 和
`cat /etc/resolv.conf`。最后验证旧网卡路由保留、DNS 解析及换热点失败回滚。
不要盲用示例地址，也不要在唯一 SSH 通道上无串口保障切换配置。

串口恢复：先备份并移走 `/etc/lawrec-ipv4.conf` 后完整重启，缺失配置采用 DHCP。
不要只删除运行态 incomplete 标记来伪装成功，也不要同时启动两个 S45 worker。
日志：`/tmp/wifi-autoconnect.log`、`/tmp/lawrec-ipv4.log`、`/tmp/lawrec-dhcp.log`。

仍待开发/验收：DHCP 长期续租、在线策略切换/恢复/地址冲突的实板证据和
真实网络持久性/连通性。应用前冲突检查增量见
[IPv4 地址冲突检测](IPv4地址冲突检测_2026-10-01.md)；尚无运行期防御。
持续客户端和在线事务已有软件实现，未验证真实热点/DHCP 行为。
